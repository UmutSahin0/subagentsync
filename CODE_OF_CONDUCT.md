# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give constructive feedback, and keep discussions about the work. Harassment, insults and personal attacks are not tolerated in issues, pull requests or any other project space.

## Reporting

If you experience or witness unacceptable behaviour, open a **confidential issue** on GitHub (or contact the maintainer privately) or contact the maintainer directly via the links in the [README](README.md#author). Reports are handled privately.

Maintainers may remove, edit or reject comments, commits, code, issues and other contributions that do not follow this code of conduct.
